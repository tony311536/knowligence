# Knowligence · 知更

Knowledge + Intelligence — 让知识有结构，让结论有依据。

面向知识探索者的证据工作台，将来源、声明、对象和工作资产连接起来。

## 本地运行

仅需 Python 3，无需 API Key 或安装依赖：

```sh
python3 -m http.server 8080 --directory public
```

打开 http://localhost:8080 。不要直接双击 HTML（数据通过 fetch 加载）。

## 功能

- 天文、酒店节能节水、NumPy 迁移三个精选资料实验场
- 知识图谱、脑图、资产目录、覆盖分析
- Captain Kiko 精选证据解释与预设问答
- 中英文、明暗主题、移动端、本地笔记与 JSON 导出
